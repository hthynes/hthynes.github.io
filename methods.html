Methods

I want to be able to explain where every number came from.

Most of my work starts before the model. I spend a lot of time figuring out what a dataset actually measures, how categories were constructed, what had to be joined or recoded, and which assumptions I would be making if I treated a variable as something it is not. Then I model it.

Quantitative analysis

R; regression modeling; marginal estimation; complex survey analysis; state-panel analysis; difference-in-differences; risk ratios; robustness and sensitivity analysis.

Data engineering

Administrative and public data integration; reproducible cleaning pipelines; schema and key validation; integrity checks; missing-data decisions; automated tables and figures.

Measurement

Denominator construction; classification validity; sensitivity to alternative measures and definitions; careful separation of observed quantities from estimates that depend on additional assumptions.

Policy & institutional analysis

Comparative policy research; statutory and regulatory analysis; implementation; administrative systems; classification systems; stakeholder mapping.

Reproducibility

If I cannot trace a result back to the data, I do not trust it yet.

I use version control, source manifests, validation scripts, integrity checks, and documented analytic specifications. I want to be able to move backward from a sentence in a paper to the output that supports it, the code that produced it, and the source data and assumptions underneath it.

Document decisions.

Test assumptions.

Track data sources and changes.

State uncertainty.

Do not outrun the design.
